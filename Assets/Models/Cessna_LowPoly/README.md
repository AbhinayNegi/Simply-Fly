# Cessna 172 Low-Poly

- Scale: 1 Unity unit = 1 meter
- Approximate dimensions: 11.0 m wingspan, 8.3 m length, 2.65 m height
- Unity forward: +Z
- Unity up: +Y
- Suggested cockpit camera anchor: `CockpitCamera`
- Suggested propeller animation pivot: `PropellerPivot`
- Suggested physics center: `CenterOfMass`

The FBX contains separate, named cockpit, control, wheel, and propeller parts. The
`.blend` file also includes a `PREVIEW_ONLY` collection with lighting and a ground
plane; these helpers are excluded from the FBX.
